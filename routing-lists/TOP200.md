# 200 популярных российских сайтов для прямого доступа

Обновлено 2026-10-25; поколение 3. 200 основных сайтов, 274 доменных правил вместе с адресами входа, API, оплаты и содержимого.

Это отобранный набор популярных и повседневных сервисов, а не измеренный рейтинг посещаемости и не список 200 доказанных блокировок VPN. При отборе учтены [Semrush](https://www.semrush.com/trending-websites/ru/all) и [Similarweb](https://www.similarweb.com/top-websites/russian-federation/), значимость платежей, государственных и бытовых услуг. Порядок строк тематический.

Существующий выбор категорий, личные правила и выключенные зоны сохранены. По умолчанию по-прежнему включены только банки и госуслуги. Отключение категории не отменяет другое включенное правило для родительского домена или зоны. Личное правило «Через VPN» имеет приоритет.

Статусы: **справка** — официальный совет отключить VPN при конкретной проблеме; **сообщество** — сообщение об ограничении зарубежного доступа; **совместимость** — профилактическое исключение без доказанной блокировки. Проверка HTTPS-источника не равна проверке входа, оплаты или маршрута через VPN. Даже прямой IP-маршрут не гарантирует устранение проверки наличия VPN самим приложением.
